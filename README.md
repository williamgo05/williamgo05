## Projetos

### Libft
Biblioteca desenvolvida em C contendo mais de 40 funções para manipulação de memória, strings e listas encadeadas, servindo como base para os projetos da Escola 42.

**Tecnologias:** C • Ponteiros • Memória Dinâmica • Listas Encadeadas • Makefile

---

### ft_printf
Implementação própria da função `printf` da biblioteca padrão da linguagem C utilizando argumentos variáveis (`stdarg.h`) e gerenciamento de memória.

**Tecnologias:** C • Variadic Functions • Recursão • Ponteiros

---

### get_next_line
Implementação de leitura linha a linha utilizando buffers e variáveis estáticas, permitindo o processamento contínuo de arquivos sem carregar todo o conteúdo na memória.

**Tecnologias:** C • Buffers • Variáveis Estáticas • `read()` • Gerenciamento de Memória

---

### push_swap
Projeto desenvolvido em parceria durante a Escola 42 São Paulo.

Desenvolvimento de um algoritmo adaptativo de ordenação utilizando duas pilhas e um conjunto limitado de operações, selecionando diferentes estratégias conforme o nível de desordem da entrada para minimizar o número de movimentos.

**Tecnologias:** C • Algoritmos • Estruturas de Dados • Big O • Listas Encadeadas
